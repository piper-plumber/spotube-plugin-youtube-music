# Spotube Plugin for Youtube Music

YouTube Music plugin for Spotube. Allows using and importing your YouTube Music library in Spotube.

This works best with NewPipe audio source plugin from Spotube. So make sure to select that as the 
default audio source when using this plugin.

> The innertube implementation was shamelessly copied from [Metrolist](https://github.com/metrolist/metrolist)
